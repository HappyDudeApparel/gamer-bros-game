# Room 01 — Crystal Training Chamber

Fast playable integration test combining the working Training Grounds combat/controls with the darker Crystal Library visual target.

This isolated room uses the canonical Gamer Bro implementation, reconstructed v04 Dash/Water/Fire/Earth/Ghost silhouettes, character-specific attacks and powers, destructible brick barriers, enemies, Maple Leaves, one Maple Crest, an Overcharge pickup, elevated traversal, moving platforms, and the newer M2-style portal machine as the earned exit.

Lighting target starts from Claude's extracted reference values: background/fog #0f0924, ACES exposure 1.15, bloom threshold ~0.528, low ambient illumination, bright emissive crystals, and localized warm counter-lights.

This is a test chamber, not a claim that the final authored Blender art pipeline is complete.
