# Crystal Library environment assets

The Hybrid v0.9 Crystal Library preview vendors the visible modular GLB assets below directly in this folder so runtime rendering does not depend on a third-party asset server.

## Kenney — Modular Dungeon Kit (CC0)
- `kenney/dungeon/gate.glb` — repeated stone gateway/arch modules around the library bays.
- `kenney/dungeon/stairs.glb` — visible stair modules fitted to the analytic stair routes.

## Kenney — Furniture Kit (CC0)
- `kenney/furniture/bookcaseOpen.glb` — library shelving bays.
- `kenney/furniture/bookcaseClosedWide.glb` — alternate wide bookcase bays.
- `kenney/furniture/lampWall.glb` — wall lamps/sconces.

Source mirror used for the vendored files: `eturner58/game-assets`, preserving the original Kenney pack structure. Kenney asset packs are released under CC0. The game keeps its own simple analytic collision surfaces; these GLBs are render meshes only.
